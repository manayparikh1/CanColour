# CanColour

This is basically a light-weight canvas that you can draw on with thousands of colours and it is also customizable with hex codes which is basically where you write any code you want and each code matches with a certain shade of colour.

It is very easy to use and you can draw literally anything you want. There are different brush weights too which span from a thin brush to a very thick brush and there is also an eraser that changes based on the weight you pick for the brush (drawing tool).

## Features

- Eraser tool
- Drawing tool
- Paintbrush thickness
- Hex codes
